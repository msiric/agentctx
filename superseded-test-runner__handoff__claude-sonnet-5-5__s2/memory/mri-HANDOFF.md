## Decisions
- Target is `node:test`, not uvu: security review blocks new devDependencies in published packages. (Earlier uvu plan abandoned; num.js was briefly uvu.)
- Mapping: `t.equal`/`t.is` -> `assert.strictEqual`; `t.deepEqual`/`t.same` -> `assert.deepStrictEqual` (tape's are strict too); `t.type`-style `typeof` checks use `strictEqual`; `t.end()` dropped; callbacks `t => {}` -> `() => {}`.
- Kept CommonJS `require`.
- `node --test test/` runs every file in test/ (no explicit file list needed now).
- Package manager is pnpm; `npm i` fails on the existing node_modules. pnpm-lock.yaml is gitignored.

## Caveats
- `node:test` needs Node >= 18 for running tests (dev only). `engines.node >=4` describes the library itself and is unchanged.
- Commented-out tests in index.js/unknown.js were mechanically converted too, but remain disabled.
