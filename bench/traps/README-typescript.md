Oracle notes: each `oracle/check.mjs` imports the repo's `src/` directly. It transpiles with the `typescript` package when one can be found (the repo's node_modules or Node's global modules), and otherwise falls back to Node's built-in type stripping (Node >= 22.6). `ORACLE_NO_TS=1` forces the fallback. The ufo traps need the TypeScript path, because ufo has type-only imports without `import type`. ms and scule work either way. `setup.sh` installs dev dependencies on a best-effort basis; the oracles don't need them.
